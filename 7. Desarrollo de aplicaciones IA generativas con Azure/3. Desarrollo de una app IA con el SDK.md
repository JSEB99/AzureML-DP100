# Desarrollo de una aplicación de IA con el SDK de Azure AI Foundry

El SDK de Azure AI Foundry está diseñado para reunir **servicios comunes y bibliotecas de código en un proyecto** de inteligencia artificial a través de un punto de acceso mediante programación central, lo que facilita a los desarrolladores escribir el código necesario para crear aplicaciones de inteligencia artificial eficaces en Azure.

## ¿Qué es el SDK de Azure AI Foundry?

- Conjunto de paquetes y servicios diseñados para trabajar juntos.
- Permite crear apps que se conecten al proyecto, acceder a las conexiones y modelos de ese proyecto
- Proporciona bibliotecas `.NET de Python y Microsoft C#` para compilar de IA

## Instalación de paquetes de SDK

El paquete para trabajar con proyectos de SDK de Azure AI Foundry es la **biblioteca de proyectos de Azure AI**. Para usarla con Python se instala con *pip* de la siguiente forma: `pip install azure-ai-projects`

## Uso del SDK para conectarse a un proyecto

Lo primero será conectarse al proyecto de Azure AI Foundry. Cada proyecto tiene un **punto de conexión único**, que se encuentra en la **información general del proyecto en el portal** de Azure AI Foundry.

**Nota:** El proyecto proporciona varios puntos de conexión y claves:
- Para el **propio proyecto**; para acceder a las conexiones, agentes y modelos del proyecto en el recurso de Azure AI Foundry
- Para las **API** del servicio *Azure OpenAI* en el recurso de Azure AI Foundry del proyecto
- Para las **API** de servicios de *Azure AI* (como Azure AI Vision y Lenguaje Azure AI) en el recurso de Azure AI Foundry

Puede usar el punto de conexión del proyecto en el código para crear un objeto **AIProjectClient** que proporciona un proxy programático para el proyecto:

```Python
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

project_endpoint = "https://....."
project_client = AIProjectClient(
    credential = DefaultAzureCredential(),
    endpoint = project_endpoint
)
```

> Para habilitar la autenticación predeterminada de Azure se debe instalar el paquete azure-identity con pip

Ademas para acceder se debe haber **accedido previamente a Azure**, esto se puede hacer mediante el **CLI** con `az-login` para iniciar sesión antes de la ejecución del código.

## Trabajar con conexiones de proyecto

Cada proyecto incluye **recursos conectados**, que se definen en el *nivel primario (recurso o centro de Azure AI Foundry)* y el *nivel del proyecto*. Cada recurso es una *conexión* a un servicio externo, como *Azure Storage*, *Azure AI Search*, *Azure OpenAI* u otro recurso de *Azure AI Foundry*.

El objeto **AIProjectClient** de Python tiene una propiedad conexiones, que puede usar para acceder a las conexiones de recursos del proyecto. Los métodos de las conexiones objeto incluyen:
- `connections.list()`: devuelve una **colección de objetos de conexión**, cada uno que representa una conexión en el proyecto. Puede filtrar los resultados especificando un parámetro de *connection_type* opcional con una enumeración válida, como `ConnectionType.AZURE_OPEN_AI`.
- `connections.get(connection_name, include_credentials)`: devuelve **un objeto de conexión para la conexión con el nombre especificado**. Si el parámetro *include_credentials* es True (el valor predeterminado), se devuelven las credenciales necesarias para conectarse a la conexión; por ejemplo, en forma de clave de API para un recurso de servicios de Azure AI.

> Los objetos de conexión devueltos por estos métodos incluyen propiedades específicas de la conexión, incluidas las credenciales, que puede usar para conectarse al recurso asociado.

```Python
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient

try:
    # Get project client
    project_endpoint = "https://...."
    project_client = AIProjectClient(
        credential = DefaultAzureCredential(),
        endpoint = project_endpoint
    )

    # List all connections in the project
    connections = project_client.connections
    print("List all connections:")
    for connection in connections.list():
        print(f"{connection.name} ({connection.type})")
except Exception as ex:
    print(ex)
```

## Creación de un cliente de chat

Conectarse a un modelo de IA generativo y usar prompts con el modelo. Con el **SDK** se puede chatear con los modelos que ha implementado en el proyecto. Las bibliotecas **dependen de como se ha implementado el modelo de destino** en el proyecto de Azure AI Foundry. Puede implementar modelos en las siguientes soluciones de hospedaje de modelos:
- **Modelos de Azure AI Foundry:** un **único punto de conexión** para varios modelos de distintos tipos, incluidos los modelos openAI y otros del catálogo de modelos de Azure AI Foundry
- **Azure OpenAI:** un único punto de conexión para **los modelos de OpenAI** hospedados en Azure.
- **API sin servidor:** una **solución de modelo como servicio** en la que se accede a cada modelo implementado a través de un punto de conexión único y hospedado en el proyecto de Azure AI Foundry.
- **Proceso administrado:** una solución de modelo-como-servicio en la que se accede a cada modelo implementado a través de un punto de conexión único hospedado en cómputo personalizado.

## Creación de una aplicación cliente para modelos de Azure AI Foundry

Cuando haya implementado modelos en el servicio de inferencia de modelos de *Azure AI*, puede usar el *SDK* de *Azure AI Foundry* para escribir código que cree un objeto **ChatCompletionsClient**, que después puede usar para chatear con un modelo implementado.

> Una ventaja es que le permite alternar entre modelos implementados cambiando un parámetro en el código

> Para implementar modelos en un punto de conexión de inferencia de modelos de Azure AI, debe habilitar la opción Implementación de modelos en el servicio de inferencia de modelos de Azure AI en Azure AI Foundry.

En el ejemplo de código de Python siguiente se usa un objeto **ChatCompletionsClient** para chatear con una implementación de modelo denominada **phi-4-model**.

```Python
from azure.ai.projects import AIProjectClient
from azure.identity import DefaultAzureCredential
from azure.ai.inference.models import SystemMessage, UserMessage


try:
    
    project_enpoint = "https://...."

    # Initialize the project client
    project_client = AIProjectClient(
        credential = DefaultAzureCredential(),
        endpoint = project_endpoint
    )

    # Get a chat client
    chat_client = project_client.inference.get_chat_completions_client()

    # Get a chat completion based on a user-provided prompt
    user_prompt = input("Enter a question: ")

    response = chat_client.complete(
        model = "phi-4-model",
        messages = [
            SystemMessage("You are a helpful AI assistant that answers questions."),
            UserMessage(user_prompt)
        ]
    )
    print(response.choices[0].messsage.content)

except Exception as ex:
    print(ex)
```

La clase **ChatCompletionsClient** usa la biblioteca de inferencia de Azure AI. Además de los paquetes de `azure-ai-projects` y `azure-identity` descritos anteriormente, el código de ejemplo que se muestra aquí supone que se ha instalado el paquete azure-ai-inference: `pip install azure-ai-inference`

## Uso del SDK de Azure OpenAI

la clase **AIProjectClient** proporciona un método `get_azure_openai_client()` que puede usar para **crear un objeto de cliente de Azure OpenAI**. A continuación, puede usar las clases y los métodos definidos en el SDK de Azure OpenAI para consumir un modelo de OpenAI implementado en *Azure Foundry Models.*

En el ejemplo de código de Python siguiente se usan los *SDK de Azure AI Foundry* y *Azure OpenAI* para chatear con una implementación de modelo denominada *gpt-4o-model*.

```Python
from azure.identity import DefaultAzureCredential
from azure.ai.projects import AIProjectClient
from openai import AzureOpenAI

try:
    # Initialize the project client
    project_endpoint = "https://..."
    project_client = AIProjectClient(
        credential = DefaultAzureCredential(),
        endpoint = project_endpoint
    )

    # Get an Azure OpenAI chat client
    openai_client = project_client.inference.get_azure_openai_client(api_version = "2024-10-21")
    
    # Get a chat completion based on a user-provided prompt
    user_prompt = input("Enter a question: ")
    response = openai_client.chat.completions.create(
        model = "gpt-4o-model",
        messages = [
            {"role": "system", "content": "You are a helpful AI assistant that answers questions."},
            {"role": "user", "content": user_prompt}
        ]
    )
    print(response.choices[0].message.content)

except Exception as ex:
    print(ex)
```

Ademas de los paquetes utilizados, se supone que se debe tener instalado *openai* de la siguiente forma `pip install openai`
